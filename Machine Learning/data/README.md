# Data used in the examples

**Concrete compressive strength.** I-Cheng Yeh’s dataset contains 1,030 measurements of compressive strength. The seven ingredient quantities are in kg/m³, curing age is in days, and the response is in MPa. The accompanying `concrete.csv` converts the UCI spreadsheet to CSV, shortens the column headings and stores up to ten significant digits. The original distribution is licensed under Creative Commons Attribution 4.0 International. [Yeh (1998), UCI](https://doi.org/10.24432/C5PK67) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

**Diagnostic cell measurements.** The classification examples load Breast Cancer Wisconsin (Diagnostic) through scikit-learn. The repository uses the published measurements and encodes malignant as the positive class. [Wolberg, Mangasarian, Street and Street (1995), UCI](https://doi.org/10.24432/C5DW2B) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

**Handwritten digits.** The 1,797 small digit images come from the UCI optical digits test partition distributed with scikit-learn. Here it is split again by image for teaching. Writer identifiers are unavailable in the bundled loader. Digit examples therefore report image-level performance. [Alpaydin and Kaynak (1998), UCI](https://doi.org/10.24432/C50P49) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Two moons, concentric circles and blobs use the generators in scikit-learn. The geometric scenes, clips, gridworlds and payoff experiments are generated by the example code. Each notebook identifies its source data or describes its generator. [scikit-learn sample generators](https://scikit-learn.org/stable/datasets/sample_generators.html)

The repository’s MIT licence covers the example code. The UCI terms above apply to the respective datasets and adapted data. Dependencies retain their own licences.
